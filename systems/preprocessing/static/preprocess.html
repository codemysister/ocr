Image preprocessing

Untuk foto KTP di latar (bukan scan): otomatis cari bidang kartu lalu luruskan. Orientasi: dukungan EXIF (foto ponsel). Putaran 90°/180°/270° default off; set PREPROCESS_AUTO_ROTATE_QUARTERS=auto atau on bila sering foto menyamping (sebelum + setelah warp). Mode auto warp memakai rotasi + crop poros bila kotak hampir lurus, perspective jika miring kuat; scan hampir penuh frame → warp dilewati agar tidak distorsi. Env: PREPROCESS_CARD_WARP, PREPROCESS_CARD_WARP_STYLE (auto atau perspective), PREPROCESS_SKIP_WARP_WHEN_COVER_RATIO, PREPROCESS_AUTO_ROTATE_* — lihat /systems/preprocessing/health. Setelah itu pencahayaan diratakan, bilateral, CLAHE, dan sharpening ringan — output grayscale 8-bit (bukan hitam-putih keras) agar teks tidak melebar dan watermark tidak “meledak”. Layanan ini dapat dipanggil dari sistem OCR melalui POST /api/v1/preprocess (field file). Header: X-Preprocess-Card-Warped, X-Preprocess-Card-Warp-Mode (axis_box|perspective|…), X-Preprocess-Auto-Rotate-90ccw (post-warp), X-Preprocess-Auto-Rotate-Pre-90ccw, X-Preprocess-Exif-Decode.
