Pipeline penuh

Satu unggahan menjalankan: POST /api/v1/preprocess?format=json → OCR (pilihan model di bawah) → validasi jenis dokumen & nama (POST /systems/validation/api/v1/validate-document). Default: PP-OCRv6 lokal (ocr_mode=fast). Alternatif: Mistral cloud atau PaddleOCR-VL. Untuk foto_profile: validasi gambar saja (wajah + latar biru) — tanpa OCR. Untuk cv: ingest ke index pencarian + opsional hybrid search — tanpa validasi dokumen.
